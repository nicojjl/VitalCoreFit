# VitalCoreFit - Hito 2 🏋️‍♂️

Plataforma integral de salud y fitness desarrollada en C++ y Qt.

## 📥 ¿Cómo descargar e instalar el programa?

Si deseas probar la aplicación final compilada para Windows (sin necesidad de compilar ni instalar Qt):

1. Dirígete a la sección de **Releases** en la columna derecha de esta página.
2. Descarga el archivo **`VitalCoreFit_Final.zip`**.
3. Descomprime la carpeta en tu computadora.
4. Haz doble clic en el archivo **`VitalCoreFit_GUI.exe`**.
5. ¡Disfruta del programa!

*(El código fuente de este proyecto se encuentra en la rama `master`)*.
